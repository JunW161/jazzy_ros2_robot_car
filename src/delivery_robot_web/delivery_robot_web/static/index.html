CẤU HÌNH TRÊN UBUNTU

Kết nối hiện tại

Địa chỉ kết nối trên máy Ubuntu.

ESP32 #1 phải dùng đúng IP máy Ubuntu và cổng Agent. Sửa cổng ở đây không thay cổng trong firmware.

USB · BUILD + APP-FLASH

Cấu hình Wi-Fi của ESP32

Tạo bản cấu hình mạng, build và nạp ứng dụng qua USB.

ESP32 sẽ khởi động lại khi nạp. Ngắt nguồn driver motor trước khi thực hiện.

ESP32 #1 sử dụng ESP-IDF 5.4.4. Kết nối đúng board và cổng USB.
