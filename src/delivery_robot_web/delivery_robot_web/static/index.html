USB · BUILD + APP-FLASH

Cấu hình Wi-Fi của ESP32

Firmware hiện tại dùng Wi-Fi trong sdkconfig. Web tạo bản cấu hình riêng, build đúng mã nguồn đang có, rồi chỉ nạp ứng dụng sau khi bạn xác nhận. Không phải ghi cấu hình Wi-Fi tức thời.

Không sửa file nguồn motor / URDF / PID. Không chạy erase-flash. Không thay bootloader, partition table hoặc chủ động ghi NVS. ESP32 sẽ reset khi nạp.

Đây là tùy chọn: Wi-Fi đang hoạt động thì không cần build/nạp. Cần đúng ESP-IDF 5.4.4 của project #1. Hãy cắm riêng board định nạp để tránh nhầm.
